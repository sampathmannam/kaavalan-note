## Physical upgrade and voice-access checks

The connected Motorola Signature (`vantage`, Android 17/API 37) started with the
signed production v2.7.4/code 57 installation. `adb install --no-streaming -r` updated
it to v2.7.5/code 58 without uninstalling or clearing data. The original installation
timestamp remained `2026-09-08 12:35:20`. A cold launch completed in 299 ms, resumed
`MainActivity`, rendered Today, Instructions, Contacts, New note, Photo and Speak, and
produced no matching fatal log entry.

The production launcher registered `speak_note` against `com.kaavalan.note` and
`MainActivity`. A separate isolated `.debug.physicalqa` install confirmed that custom
debug suffixes now register the shortcut against their own package rather than the
ordinary debug app. The disposable QA package and test package were removed afterward;
the production and existing normal debug installations were not uninstalled or cleared.

The Android 17 Quick Settings smoke check exercised the system PendingIntent launch,
observed no background-activity-launch block, started the visible Listening state, then
stopped the voice foreground service and removed its notification on a second request.
The temporary debug tile was removed after verification.

## Tag CI timing-flake disposition

The first tag-CI emulator attempt reported two synchronization failures while the same
candidate had already passed the physical-device aggregate. One test tried to click the
date-dialog confirmation before it entered Compose semantics; a screenshot-oriented test
allowed only 15 seconds for a cold encrypted save on the loaded arm64 emulator. Neither
failure contained a production crash, database error or assertion against saved data.

The two scenarios were rerun in isolation after adding explicit dialog readiness and a
30-second encrypted-save completion budget; both passed. The exact immutable v2.7.5 tag
was then rerun without those test-only changes and passed all 41 emulator tests (39 passed,
2 expected skips), plus the external forced-Doze reminder probe. The durable test-harness
hardening is retained after the tag in commit `73fa478` for future release gates.

## Boundaries

The physical aggregate intentionally skips synthetic ContactsProvider injection; that
case belongs to the isolated emulator package. The reminder Doze scenario must be driven
outside Test Orchestrator and passed through the dedicated host script. Google Drive
OAuth is not configured in this checkout, so no live account round trip is claimed.
This pass is not a multi-OEM speech-accuracy study, TalkBack certification or a
multi-day soak test.

The GitHub tag CI began after publication; the local release gates and physical-device
evidence above were complete before the release was made public. Its final rerun result is
green and linked in the automated-verification table.
