## Outcome

The v2.7 field-notebook interface is implemented on its development branch. It keeps the
product's three primary destinations — Today, Instructions and
Contacts — and exposes subdivision review, matters, stations and staff as labelled entry
rows inside those destinations. Settings remains a top-bar action and quick capture
remains the persistent primary action.

The visual language is now a restrained Material 3 field notebook: deep service blue,
cool paper surfaces, slate text, restrained teal accents, outline-led grouping and no
gradients, glass, streaks, rankings or red lateness treatment. Light and dark themes use
the same hierarchy. Empty, populated, search-no-result, retryable-error, keyboard,
landscape and 150% text states have explicit coverage.

No merge, tag, signing operation, publication, production install or real officer-data
operation was performed. The application ID, Room schema 18 and backup schema 4 are
unchanged; versionCode advances from 52 to 53.

## Implementation summary

- Added shared notebook primitives in
  `app/src/main/java/com/kaavalan/note/ui/components/KaavalanSurfaces.kt` for top-bar
  titles, icon tiles, badges, search, panels, outlined fields, section headings and empty
  states.
- Reworked the workspace hierarchy, three-tab navigation, persistent capture bar,
  onboarding, focused settings categories and pinned editor actions.
- Brought subdivision review, matters, stations, staff, details and editors into the same
  spacing, typography, surface and action system.
- Kept local staff records distinct from accounts and retained the explicit explanation
  that marking staff creates no account and sends nothing.
- Removed the duplicate first-use action from the empty Staff list and retained its
  `add_from_contacts` automation hook on the single visible action.
- Made visual-review tests select Light explicitly before light and large-text captures;
  the results no longer depend on the emulator's system theme.
- Added source-level v2.7 design-contract coverage in
  `app/src/test/java/com/kaavalan/note/ui/components/FieldNotebookSurfacesTest.kt`.
