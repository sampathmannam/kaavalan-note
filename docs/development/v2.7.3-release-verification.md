remains `com.kaavalan.note`, versionName advances to `2.7.3` and versionCode to `56`
from the latest published v2.7.2/code 55. Room stays at schema 18 and the manual

- The palette implementation previously passed six Android 14/API 34 device

- The staged palette/version/release-note diff passed Gitleaks with zero findings,
  and `git diff --cached --check` and `bash -n release.sh` passed.

## Local build-output repair

The first signed release build stopped at R8: a stale incremental transform had
omitted `KaavalanApplication_GeneratedInjector.class`, although it existed in
the release javac output. Only
`app/build/intermediates/classes/release/transformReleaseClassesWithAsm` was moved
to a temporary backup. Regenerating it with the build cache disabled restored the
class and R8 passed. No source, keep rule or test assertion was changed to bypass
the failure. Builds used JDK 17, isolated Gradle/Android/test homes, one worker,
in-process Kotlin compilation and a 1536 MiB heap. Unrelated processes were not
stopped.
