# KaavalanNote v2.5.0 — Instructions you can follow through

versionCode: 51
versionName: 2.5.0

One signed universal APK, updating the existing KaavalanNote installation.

## What changed

- Today puts follow-ups first, with short previews and an explicit way to see all your work.
- Keep a dated, private update history on each instruction after a call or review. Record progress and when you want to check again.
- Set the work's deadline separately from your next follow-up reminder. Moving one does not move the other.
- Use “Ready to verify” for reported completion, then verify and mark done yourself. Immediate Undo restores the previous progress state.
- Edit saved instructions and local contact details, including rank and station. Contact timelines open the same instruction actions as Today and Instructions.
- Search instruction and update text across all records, with clear All/Open/Closed filters and a separate responsibility filter.
- Readable detail text, pinned actions, light/dark styling and keyboard-safe editors support everyday use, including enlarged text and landscape.
- Copying a follow-up or opening Android's share chooser is recorded as preparation, not confirmed delivery.

## Update the same app

This is an in-place update to `com.kaavalan.note`. Keep the existing installation and the same Obtainium entry; do not uninstall or install a separate debug app. Publication requires the existing pinned release certificate and the increased versionCode 51.

Database migration 16 → 17 preserves existing notes, contacts and reminder times. Old reminders are not reinterpreted as deadlines. Backups and plain exports include the new deadline and update history; older backups remain readable. As a precaution before any database upgrade, make a backup through the app's existing backup/export controls.

Updates are your own private working notes. They do not send messages to staff, prove delivery or create a shared team workspace. Contact edits apply only within KaavalanNote, not to the phone's address book.

## Verification

The implementation passed 742 unit tests with 12 existing skips, Android lint with zero errors, debug builds and nine selected Android end-to-end/visual checks. These covered editing, dated updates, independent reminder/deadline values, verification/Undo, recreation, closed-record search, contact-linked workflows, 150% text in landscape with the keyboard, light/dark screens, reminder delivery actions and contact import beyond the former limit.

The version-bumped candidate also passed the complete optimized release build and signature/alignment checks. An actual signed v2.4.1 → v2.5.0 emulator upgrade preserved the existing instruction; a new private update, progress and next follow-up persisted after a full app-process restart, without changing the deadline.
