# KaavalanNote v2.7.2 — End-to-end hardening

versionCode: 55
versionName: 2.7.2

This is an in-place security and reliability update to the existing
`com.kaavalan.note` application. Room remains at schema 18 and the manual backup
format remains at schema 4, so this release introduces no data migration.

## What changed

- Google OAuth callbacks now require the exact configured action, scheme, host,
  port and path. PKCE verifier state is compared in constant work and consumed
  before token exchange, preventing replay without allowing a mismatched callback
  to erase an active login.
- Google Drive operations bound and validate identifiers, page sizes and filenames.
  Multipart filenames cannot inject headers, remote error bodies are not exposed,
  and encrypted downloads remain raw bytes instead of passing through text encoding.
- Backup and restore workers propagate cancellation, keep failures generic and clear
  mutable key material when work completes.
- Local crash logs exclude exception messages while retaining exception types and
  stack structure for diagnosis. Reviewed application paths no longer log raw remote
  or throwable messages.
- Cleartext traffic is disabled. OAuth history/recents behavior is restricted,
  widget receivers are non-exported, and Android device-transfer rules exclude files,
  databases, preferences and external storage.
- Administrative edge-function tokens use constant-work comparison. Inputs are
  bounded, IDs are UUID validated, database details stay server-side, and MCP search
  no longer constructs raw PostgREST filter syntax from user text.
- All third-party GitHub Actions are pinned to immutable upstream commit hashes, and
  workflow values cross into shell steps through environment variables.

## Existing v2.7 experience retained

The day-first reminder picker, heads-up notification with Snooze and Done, streaming
voice partials, compact status-coloured cards and multi-contact import remain in this
build. The three-tab Today / Instructions / Contacts structure and local-first privacy
model are unchanged.
