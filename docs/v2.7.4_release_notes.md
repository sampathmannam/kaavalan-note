# KaavalanNote v2.7.4 — Reliable field notebook

versionCode: 57
versionName: 2.7.4

## What changed

- Saving an instruction, a capture and its delivery marker now happens in one
  transaction. A failed write cannot leave partial work behind.
- Restore and plain import validate and bound incoming data before applying it.
  Local backup publication is atomic, with safe cleanup and predictable retention.
- Reminders use an allow-while-idle Android alarm together with a durable
  WorkManager fallback, and are restored after restart or app update. Precise timing
  remains an explicit Settings choice so it cannot pull someone out of note entry.
- Voice, contacts, Today, search and person-detail actions report safe errors without
  replacing the healthy screen content. The contacts provider remains read-only.
- Android-native tests now exercise encrypted preferences, vault encryption and the
  historical SQLCipher migration on real Android runtimes. Reminder delivery was also
  checked after process death under forced Doze on both an Android 14 emulator and a
  connected Android 17 phone.

Package `com.kaavalan.note`, Room schema 18, manual backup schema 4 and the pinned
release signing identity are unchanged. Existing local data is preserved by the normal
in-place Android update. Optional Google Drive backup is unavailable unless this build
is supplied with its production OAuth configuration; local encrypted backups remain
available.

The release candidate passed all 886 JVM tests across 156 suites, with no failures,
errors or skips. Android lint completed with zero errors or fatals; debug and optimized
release variants assembled. The 41-test Android aggregate passed 39 tests with two
