# KaavalanNote v2.7.3 — Plum notebook

versionCode: 56
versionName: 2.7.3

## What changed

- Muted plum replaces blue interface accents. Light mode combines white cards,
  a neutral background and charcoal text; dark mode has coordinated plum accents
  and charcoal surfaces.
- Instruction cards and detail sheets share labelled status colours: neutral Open,
  plum In progress, amber Waiting, muted green Ready to verify and grey Closed.
  Only verified Done receives a checkmark. Card tints remain restrained.
- Widgets, quick capture and native startup surfaces use the same palette.
  The existing shield launcher artwork is unchanged.
- Contrast regression tests cover text roles and every status badge/card in both
  themes. Native visual checks also cover large text, landscape and capture with
  the keyboard open.

The reminder picker, heads-up alerts with Snooze, voice capture, multi-contact
import and v2.7.2 security hardening are retained. No dependency, database migration
or backup-format change is introduced: package `com.kaavalan.note`, Room schema 18
and backup schema 4 remain unchanged.

## Verification

The palette implementation passed 873 JVM tests (12 existing skips), Android lint
with zero errors, debug assembly and six Android 14 device scenarios. Tested text
contrast pairs meet 4.5:1. This is not a complete accessibility or physical-device
audit. Release artifact and upgrade evidence is recorded separately in
`docs/development/v2.7.3-release-verification.md` after the release gates complete.

Install as an update through the existing Obtainium entry or the signed APK.
Do not uninstall the current app; Android retains its encrypted local data during
an in-place update with the unchanged production signing identity.
