# KaavalanNote v2.7.0 — A calmer field notebook

versionCode: 53
versionName: 2.7.0

An in-place update to the existing KaavalanNote installation.

## What changed

- A consistent field-notebook hierarchy now runs through onboarding, Today,
  Instructions, Contacts, quick capture, settings and subdivision records.
- The interface uses deep service blue, cool paper surfaces, slate text and restrained
  teal accents in complete light and dark treatments. Grouping is outline-led, without
  gradients, glass, decorative dashboards, streaks, rankings or red lateness badges.
- Today, Instructions and Contacts remain the only primary destinations. Subdivision
  review, matters, stations and staff are clear entry rows inside the relevant tab rather
  than a fourth destination.
- Shared top-bar titles, icon tiles, badges, search fields, panels, section headings,
  outlined fields and empty states make density and actions predictable across screens.
- The persistent note bar keeps New note primary while Photo and Voice remain separate,
  reachable 48dp-or-larger actions.
- Editors preserve their Save action above the keyboard and remain usable in landscape
  and at 150% system text.
- First-use, populated, no-results and retryable-error states are distinct. Empty lists
  present one action instead of repeating the same control.
- Settings categories have a focused, icon-led hierarchy. Staff remain local records,
  never app users: marking somebody as staff creates no account and sends nothing.
- Visual-review automation now selects Light explicitly before light and large-text
  screenshots, so evidence is independent of the emulator's system theme.
- The repository includes a Penpot-ready v2.7 package with 27 screen boards and three
  component/token reference sheets.

## Update the same app

The public application ID remains `com.kaavalan.note`. Room stays at schema 18 and the
manual backup format stays at schema 4, so v2.7.0 introduces no new data migration.
Existing notes, contacts, instructions, reminders, subdivision records and review
history remain in place during a correctly signed in-place update.

Do not uninstall the current app to update it. Publication must use the existing pinned
release certificate; a differently signed APK cannot update the installed app and an
uninstall would erase this local-only database.
