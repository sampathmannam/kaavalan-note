# KaavalanNote v2.7.5 — Voice-first field capture

versionCode: 58
versionName: 2.7.5

## What changed

- Voice capture has explicit Starting, Listening and Adding your words states. A calm
  live pulse, supporting text and an in-app Stop action make microphone state visible.
- Spoken notes that contain `today` or `tomorrow` together with a time automatically
  prepare that follow-up. The full spoken text stays editable before save.
- A labelled **Speak** action is available in the note bar. Voice can also be started
  from the **Kaavalan Speak** launcher entry, home-screen widget, Quick Settings tile,
  or the normal app icon's long-press **Speak note** shortcut.
- The Quick Settings tile uses Android's system-mediated activity launch on Android 14+
  and starts or stops the current capture. Repeated requests are queued so a second
  gesture cannot disappear while the app returns from the system shade.
- Custom isolated debug builds now target their own application ID from launcher
  shortcuts, preventing QA gestures from opening a different installed build.

Package `com.kaavalan.note`, Room schema 18, manual-backup schema 4 and the pinned
production signing identity are unchanged. This is a normal in-place update that keeps
existing encrypted notes, reminders, contacts and subdivision records.

## Verification

- All JVM tests pass with no failures, errors or skips.
- Android lint passes with zero errors or fatals; debug and R8-optimized release
