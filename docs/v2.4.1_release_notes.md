# KaavalanNote v2.4.1 — Find all your phone contacts

versionCode: 50
versionName: 2.4.1

## What changed

- Removed the old 50-entry limit from phone-contact import.
- Search all Android-accessible contacts by name or phone number, including Tamil names and formatted numbers.
- Import contacts without phone numbers. People sharing a station number stay separate; contacts with several numbers let you choose the right one.
- Clear contact-access guidance, retry and refresh controls replace confusing empty results. Large address books load without blocking the interface.

Only the selected contact is copied into KaavalanNote. Your phone address book is never modified by import. Android profile and permission boundaries still apply.

## Existing app and data

This is an update to the same `com.kaavalan.note` app, not a second app. The database schema and backup format are unchanged. Keep the existing installation and update it through its current Obtainium entry; do not uninstall it. Publication requires an APK signed with the existing pinned release certificate.
