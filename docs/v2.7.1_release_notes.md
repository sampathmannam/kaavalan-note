# KaavalanNote v2.7.1 — Easier reminders and faster capture

versionCode: 54
versionName: 2.7.1

This is an in-place update to the existing `com.kaavalan.note` application. Room
remains at schema 18 and the manual backup format remains at schema 4, so the update
does not introduce a data migration.

## What changed

- Reminder setup now starts with familiar choices: Today, Tomorrow, This week or This
  month. After choosing a day, the app shows practical times and keeps exact date/time
  pickers available when needed.
- Reminder notifications use a high-importance channel for an on-screen heads-up banner,
  a short normal notification sound and a gentle vibration. Snooze for one hour is the
  first notification action, followed by Done. Android's user-controlled notification
  settings still determine whether a device shows banners or plays sound.
- Voice capture streams partial speech into the open note, replaces earlier partial
  guesses instead of duplicating them, prefers the on-device recognizer when available,
  and tolerates short pauses between names, ranks and places.
- Today and instruction cards are thinner. Open, in-progress, waiting and closed states
  use restrained Material colour families while preserving accessible text contrast and
  the product rule against red lateness treatment.
- Phone-contact import supports multi-selection across searches, one selected number per
  source contact, Select all results, Clear selection and one atomic batch save. The
  source address book remains read-only.

## Data and privacy

The public application ID remains `com.kaavalan.note`. Existing notes, instructions,
contacts, reminders, subdivision records and history remain in place during a correctly
signed update. Contact import reads only the rows the user selects. Voice recognition is
provided by Android and may use an online recognizer depending on the device; the app
requests offline recognition first.

Do not uninstall the current app to update it. The APK must be signed with the existing
pinned release certificate so Android can install it over the current version without
erasing the local database.
